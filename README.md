# unhingedpanda/tap

Homebrew casks for [Cans](https://github.com/unhingedpanda/cans), the menu bar controller for Sony WH-1000XM4 and WH-1000XM5 headphones.

```sh
brew install --cask unhingedpanda/tap/cans
```

Cans isn't notarized yet, so macOS blocks the first launch: open it once, then click **Open Anyway** in System Settings → Privacy & Security.
